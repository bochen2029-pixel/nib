## 2 · What nib does differently, and why

- **The floor rule is nib's own and has no counterpart in K5.** K5 speaks into a console; nib
  writes into a document somebody else is typing in. SPEC 6.3.1–6.3.2 and the review's §5.1: an
  emission targeting a block a human has touched within the floor window is refused *before it is
  composed*, and the refusal is a row. That is a serializer rule over the op log — a dependency
  test in op-space — and it is the part of Stage 2 with no prior art to lift.
- **The forming plane is the pad's.** K5's "forming plane" is stdout, and its `aired` prefix is
  console-accounted. In nib the forming text is a fourth plane of the buffer: rendered, never in
  the `Doc`, never saved, so rule 3 is structural (SPEC 6.4.1).
- **Placement.** K5 appends a lane-headed line to a stream. nib commits a *block* through
  `Doc::apply` with the seat as author, which ends the human's undo history (SPEC 2.3.5) — a cost
  the spec already priced.
- **Refused: the interruption budget as a wall-clock constant.** K5's `refractory_s` is 20 s of
  wall time. nib keeps it, but the pad has a better clock: the human's own keystrokes. The floor
  window already measures that, so nib's refractory is a manners rule about *restatements* only,
  as K5's own calibration concluded (its comment at `2271-2280`), and never about new conditions.
- **Refused: gear 2, the briefs and the counsel loop** (`write_brief` `1603`, `counsel_admit`
  `1636`). A second model between beats is a different product; nib's Act I is one mind and one
  pad, and the file-based counsel channel would be a network by another name.
- **Refused: the verdict wire as a second file.** nib has one record. The tape carries every
  judgment already, and a projection can be derived from it whenever something needs one.

## 4 · What K5 has that nib should not take, at any stage

- `ggml_backend_load_all_from_path` (`1395`) pulls `ggml-rpc.dll`, and with it ws2_32, into the
  process. nib loads backends by name and refuses to start if a network module is present.
- The tape chain `blake2b(prev_hex ‖ body)` with `prev`/`h` on every row. nib's tape is the
  family's six-key REGISTRAR format that `glance --verify` reads.
- One model per process. nib loads a second when the AI switch is flipped twice, which is where
  the cuBLAS cliff of SPEC 6.2.12 lives; K5 would never have met it.
